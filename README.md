# Workspace

Repositorio dedicado a resolver ejercicios de algoritmos, con el fin de fortalecer la lógica de programación.

## Contenido

- **Two sum/**: Solución al clásico problema "Two Sum" (dado un arreglo de enteros y un target, encontrar los índices de dos números cuya suma sea igual al target).

## Propósito

Se irán agregando nuevos ejercicios con el tiempo para fortalecer la lógica y el razonamiento propios frente a distintos tipos de problemas.
